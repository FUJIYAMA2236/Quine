# QUINE

**HTMLファイル1つで動作する、社内向けのWiki（文書管理ツール）です。**

アプリケーションと記事のデータは、すべて `quine.html` という1つのファイルに収められています。
サーバやインターネット接続は不要で、ファイルをブラウザで開くだけで利用できます。

> [!IMPORTANT]
> **QUINE は「自分自身を書き換えて保存する」ファイルです。**
> 一般的なアプリケーションとは保存の仕組みが大きく異なります。この点を誤解したまま利用すると、**入力した内容が失われたり、他の利用者の変更を上書きしたりするおそれがあります。**
> ご利用の前に、必ず「[保存の仕組み（必ずお読みください）](#保存の仕組み必ずお読みください)」をお読みください。

## 保存の仕組み（必ずお読みください）

### 概要

QUINE には、記事を保管するサーバやデータベースがありません。**記事のデータは `quine.html` というファイル自体に格納されています。**
そのため、保存は次の流れで行われます。

1. `quine.html` をブラウザで開きます。
2. 記事を編集します。**この時点では、変更内容はブラウザ上にのみ存在します。**
3. 「保存」を押すと、最新の記事を含んだ **新しい `quine.html` がダウンロードされます。**
4. 保存のダイアログで、**現在開いている元の `quine.html` を選択して上書きします。**
5. この上書きによって、初めて共有フォルダのファイルが更新されます。

すなわち、QUINE における「保存」とは、**自身の新しい版を書き出し、元のファイルと置き換えること**です。上書きが完了するまで、保存は完了していません。

なお、名称の由来である「クワイン（quine）」も、自分自身を出力するプログラムを指す言葉です。

### よくある誤解と、その結果

| 誤解 | 実際の仕組み | 結果 |
| --- | --- | --- |
| 編集すると自動で保存される | 変更内容はブラウザ上にのみ存在します | 保存せずに閉じると、**入力した内容は失われます**（閉じる前に確認が表示されます） |
| 「保存」を押せば、共有フォルダのファイルが更新される | 「保存」は新しいファイルを**ダウンロードするだけ**です | 保存のダイアログで元のファイルに上書きしない限り、**共有フォルダのファイルは更新されません** |
| ダウンロードフォルダに保存されたファイルでも問題ない | 別の場所・別の名前（例：`quine (1).html`）のファイルは、**別のWiki**として扱われます | 他の利用者は古いファイルを参照し続けます。**次に誰かが編集・保存すると、その変更は失われます** |
| 保存のダイアログで「キャンセル」しても、「未保存」の表示が消えたので問題ない | ブラウザからは、ファイルが実際に保存されたかを確認できません。QUINE は**ダウンロードを開始した時点で「保存済み」と表示します** | 実際には保存されていません。改めて「保存」を押してください |
| 2人が同時に編集しても、両方の変更が統合される | 変更を自動で統合する機能はありません | **後から上書きした内容だけが残り**、先に保存した変更は失われます |
| パスワードを忘れても、作成者や管理者であれば開ける | パスワードから生成した鍵がなければ、内容を復元できません | パスワードで保護したWikiは、**パスワードを忘れると誰も開けなくなります** |
| QUINE を新しい版に更新すれば、既存のWikiも更新される | 各Wikiファイルは、作成時のアプリケーションを**それぞれ内部に保持しています** | 既存のWikiファイルは、作成時の版のまま動作します。新しい版の機能を使うには、記事の移行が必要です（[新しい版への移行](#新しい版への移行)を参照） |
| このファイルはアプリケーションだけで、記事は別の場所にある | 記事と画像は**すべてこのファイル内**に格納されています | ファイルをメールで送付したり持ち出したりすると、**すべての記事を渡したことになります** |

### 必要なブラウザの設定

保存のダイアログが表示されないと、元のファイルに上書きできません。ご利用の前に、次の設定を一度だけ行ってください。

- **Microsoft Edge**：「設定」→「ダウンロード」を開き、**ダウンロードのたびに保存先を確認する設定を有効**にします。

この設定が無効のままだと、「保存」を押すたびにダウンロードフォルダへ別のファイル（`quine (1).html` など）が作成されます。

### 保存の手順

1. 画面右上の **「保存」**（または Ctrl+S）を押します。
2. 保存のダイアログで、保存先が**現在開いているファイルと同じ場所・同じ名前**になっていることを確認します。
   （共有フォルダの `quine.html` を開いている場合は、共有フォルダを開いて `quine.html` を選択します。）
3. 「置き換えますか？」と表示されたら **「はい」** を押します。
4. 必要に応じて、エクスプローラーで当該ファイルの **更新日時** が現在の時刻になっていることを確認します。

## 特長

- **開くだけで利用可能**：インストールは不要です。共有フォルダに置き、ダブルクリックで開きます。
- **Word と同様の操作で記述**：見出し・太字・箇条書き・チェックリスト・リンク・画像に対応しています。記法を覚える必要はありません。
- **Excel 風の表**：マス目をなぞって表を作成できます。Excel からの貼り付け、Excel への貼り戻しにも対応しています。
- **記事の階層化**：左側のツリーで記事を入れ子にでき、ドラッグで並べ替えられます。
- **検索**：タイトルと本文（表の内容を含む）を検索できます。全角・半角、カタカナ・ひらがなの違いは区別しません。
- **リンク候補の提示**：記事中に他の記事のタイトルや見出しと同じ語句がある場合、リンクの候補を提示します。選択した候補のみがリンクになります。
- **完全オフライン**：外部との通信は一切行いません（ブラウザに対しても通信を禁止しています）。
- **パスワード保護（任意）**：Wikiの内容を暗号化して保存できます。

## 使い方

### 開く

`quine.html` をブラウザで開きます。Microsoft Edge を推奨します（Google Chrome でも動作します）。

### 閲覧・検索

- 画面左側の「記事の一覧」から記事を選択すると、画面右側に内容が表示されます。
- 画面上部中央の「検索欄」に語句を入力すると、該当する記事を検索できます。

### 編集

1. 記事の右上にある **「編集」** を押します。
   - このとき、**ファイルの最新版を自動で読み込み直してから**編集が始まります（他の利用者が保存した内容を失わないための仕組みです）。
   - 画面上部がオレンジ色になっている間が編集中です。
2. 初回のみ、氏名の入力を求められます。入力した氏名は記事の「最終更新者」として記録されます。
3. 本文の上に表示されるツールバーから、文字の装飾、表、画像を挿入できます。
4. 記事の追加・削除・並べ替えは、記事の一覧の「…」メニュー、またはドラッグで行います。
5. 編集が終わったら「編集を終える」を押します。他の記事と関連する語句がある場合は、リンクの候補が表示されます。
6. **最後に必ず保存します**（[保存の手順](#保存の手順)を参照）。

### 新しいWikiの作成

画面右上のメニュー（≡）→ **「新規Wiki開設」** から、記事が空の新しいWikiファイルを作成できます。
作成されるファイルには、現在使用しているアプリケーションがそのまま含まれます。

### 記事の移動（エクスポート・インポート）

- 記事の「…」メニューから、記事を JSON ファイルとして書き出せます（子記事・画像を含めることもできます）。
- 書き出したファイルは、メニューの「インポート」、または画面へのドラッグで取り込めます。
- 同じ記事がすでに存在する場合は、新旧の内容を並べて比較したうえで、「置き換える／別記事として追加／取り込まない」を選択できます。

## セキュリティ

### QUINE が自動で行う保護

| 保護の内容 | 仕組み |
| --- | --- |
| 外部への情報送信の防止 | 外部と通信する処理を持たないことに加え、ブラウザに対して外部との通信・外部資源の読み込みを禁止しています（Content Security Policy）。不正な内容が混入した場合でも、外部へ送信されることはありません |
| 実行できるプログラムの限定 | ファイル内で実行を許可しているのは、配布したプログラムのみです（プログラムのハッシュ値をブラウザに登録しています）。記事に混入したスクリプトや `onclick` 属性などは実行されません |
| 危険な書式の除去 | 記事の表示時、貼り付け時、インポート時に、許可した書式（見出し・太字・文字色・リンク・表・画像など）以外を除去します |
| 破損したデータの検出 | データ部分が破損している、または形式が不正な場合は、**編集画面を表示せず「開けませんでした」と表示します**。破損したまま上書き保存し、被害が拡大することを防ぎます |
| 不正なファイルの取り込み防止 | インポートするファイルの形式・ID・画像の種類・サイズを検証し、1か所でも不正があれば何も取り込みません |
| リンクを開く前の確認 | 外部のページやファイルへのリンクは、リンク先を表示して確認を求めてから開きます。登録されていないサーバへのファイルリンク（`\\サーバ名\…`）には、強い警告を表示します |

### 信頼する社内サーバの登録

ファイルリンク（`\\サーバ名\共有フォルダ\…`）を使用する場合は、メニュー（≡）→「設定」→「信頼する社内サーバ」に、社内のファイルサーバ名を登録してください（編集モードで変更できます）。
登録されていないサーバへのリンクを開こうとすると、強い警告が表示されます。Windows では、見知らぬサーバ上のファイルを開くだけで、パソコンの認証情報が相手のサーバへ送信される場合があるためです。

### パスワードによる保護（任意）

メニュー（≡）→「設定」→「パスワードで保護する」から、Wikiの内容（記事・画像）を暗号化して保存できます（編集モードで設定し、保存した時点で反映されます）。

- ファイルを開く際にパスワードの入力が求められます。ファイルが持ち出された場合でも、パスワードがなければ内容を読むことはできません。
- 暗号方式は AES-256-GCM です（鍵はパスワードから PBKDF2-SHA256 により60万回の反復計算で生成します）。内容が改ざんされた場合も、開く際に検出されます。
- 「編集」を押した際の再読み込みでは、同じタブ内でのみ鍵を一時的に引き継ぐため、パスワードを再入力する必要はありません。

> [!CAUTION]
> **パスワードを忘れると、誰も記事を開けなくなります。** 作成者・管理者を含め、復元する手段はありません。パスワードは安全な場所に控えておいてください。
> また、パスワードで保護している場合でも、**エクスポートした JSON ファイルは暗号化されません。** 取り扱いにご注意ください。
> なお、Wikiの名称のみ、パスワード入力画面に表示するため暗号化していません。

### アプリケーションの改ざん確認（フィンガープリント）

QUINE のプログラム部分（記事データを除く部分）から算出したハッシュ値（SHA-256、以下「フィンガープリント」）を、[FINGERPRINT.txt](FINGERPRINT.txt) に記載しています。記事を保存してもフィンガープリントは変化しないため、運用中のWikiファイルについても確認できます。

- **簡易的な確認**：メニュー（≡）→「このツールについて」に表示されるフィンガープリントが、FINGERPRINT.txt の値と一致することを確認します。
- **厳密な確認**：アプリケーション自身が表示する値は、アプリケーションごと改ざんされている場合には信頼できません。PowerShell で次のコマンドを実行し（`quine.html` の部分は確認するファイル名に置き換えてください）、表示された値を FINGERPRINT.txt と照合してください。

```powershell
$t = [IO.File]::ReadAllText((Resolve-Path '.\quine.html'), [Text.Encoding]::UTF8) -replace "`r`n", "`n"
$s = [regex]::Match($t, '<style>([\s\S]*?)</style>').Groups[1].Value
$j = [regex]::Match($t, '<script id="quine-app">([\s\S]*?)</script>').Groups[1].Value
$h = [Security.Cryptography.SHA256]::Create().ComputeHash([Text.Encoding]::UTF8.GetBytes($s + "`n" + $j))
($h | ForEach-Object { $_.ToString('x2') }) -join ''
```

同じ処理を行うスクリプトを `tools/verify-fingerprint.ps1` として同梱しています。
記事を作成していない配布用の `quine.html` については、ファイル全体のハッシュ値（`Get-FileHash .\quine.html`）でも確認できます（FINGERPRINT.txt に記載の2つ目の値）。

### QUINE だけでは防げないこと

- **記入者の証明**：「最終更新者」は各利用者が入力した氏名であり、なりすましが可能です。確実な記録が必要な場合は、ファイルサーバのアクセスログをご利用ください。
- **書き込み権限を持つ者による改ざん**：データとアプリケーションが同じファイルにあるため、ファイルへの書き込み権限を持つ者はアプリケーションも書き換えられます。共有フォルダの書き込み権限で保護してください。
- **記事単位の閲覧制限**：ファイルを開ける利用者は、すべての記事を閲覧できます。閲覧範囲を分ける必要がある場合は、Wikiファイルを分割し、フォルダの権限で管理してください。
- **バックアップ**：誤った上書きや破損に備え、ファイルサーバの「以前のバージョン」機能や定期的なバックアップをご利用ください。

## 複数人での利用

- **同じファイルを同時に編集しないでください。** QUINE には、他の利用者が編集中かどうかを検知する手段がありません。後から上書きした内容だけが残ります。
- 編集は短時間で区切り、**編集後は速やかに保存**してください。
- 「編集」を押すと最新版を読み込み直すため、**編集を始める直前に「編集」を押す**ことを推奨します。長時間開いたままの画面から編集を始めることは避けてください。
- 誤って上書きした場合は、相手に該当する記事をエクスポートしてもらい、それをインポートすることで、記事ごとに内容を比較しながら取り込めます。

## バックアップ

Wiki は1つのファイルで構成されているため、**ファイルを複製するだけでバックアップになります。**
大規模な編集の前や週に一度など、区切りのよい時点で日付を付けた複製（例：`quine_2026-10-25.html`）を保存しておくことを推奨します。

## 新しい版への移行

各Wikiファイルは、作成時のアプリケーションを内部に保持しています。**新しい版の `quine.html` を配置しても、既存のWikiファイルは自動では更新されません。**
新しい版の機能を利用する場合は、次の手順で記事を移行してください。

1. 新しい版の `quine.html` を開き、メニューの「新規Wiki開設」から新しいWikiファイルを作成します。
2. 既存のWikiファイルで、最上位の階層の記事ごとに「子記事も含めてエクスポート」を実行します。
3. 新しいWikiファイルで、書き出したファイルを順に「インポート」し、保存します。
4. 新しいファイルに問題がないことを確認したうえで、既存のファイルと置き換えます。

## 動作環境

| 項目 | 内容 |
| --- | --- |
| ブラウザ | Microsoft Edge（推奨）。Google Chrome でも動作します |
| 配置場所 | 共有フォルダまたは各パソコン内。ファイルを開くだけで利用できます（サーバは不要です） |
| ファイルサイズ | 画像を貼り付けるほど大きくなります。画面右上のメニュー（≡）で現在のサイズを確認できます |

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `quine.html` | 配布用のファイルです。これ1つで動作します（記事は「はじめに」のみ収録しています） |
| `src/` | ソースコードです（機能や外観を変更する場合に使用します） |
| `FINGERPRINT.txt` | アプリケーションのフィンガープリント（改ざんの確認に使用する値）です |
| `tools/verify-fingerprint.ps1` | フィンガープリントをファイルの外部から算出する PowerShell スクリプトです |
| `LICENSE` | ライセンス（0BSD）です |
| `THIRD_PARTY_NOTICES.md` | 参考にした著作物の著作権表示とライセンス文です |

> [!WARNING]
> 記事を作成したWikiファイルには、すべての記事と画像が含まれています。**社内の資料を含むファイルを、GitHub などの公開された場所に置かないでください。**

### ソースコードからの生成

`src/` 内のファイルを変更した後、[Node.js](https://nodejs.org/) がインストールされた環境で、このフォルダにて次のコマンドを実行すると、`quine.html` と `FINGERPRINT.txt` が再生成されます。

```
node src/build.js
```

プログラムを変更するとフィンガープリントも変わるため、公開する際は `quine.html` と `FINGERPRINT.txt` を必ず同時に更新してください。
