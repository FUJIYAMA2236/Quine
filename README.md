# QUINE

**HTMLファイル1枚で動く、社内向けのWiki（ドキュメント管理ツール）です。**

アプリと記事のデータが、すべて `quine.html` 1つのファイルに入っています。
サーバもインターネット接続も不要で、ファイルをブラウザで開くだけで使えます。

名前は **QUINE Unfolds Its Nested Entries**（QUINEは入れ子の記事を展開する）の頭文字です。
自分自身を出力するプログラム「クワイン」にちなんでいます。

## 特徴

- **開くだけで使える**：インストール不要。共有フォルダに置いて、ダブルクリックで開きます
- **Word感覚で書ける**：見出し・太字・箇条書き・チェックリスト・リンク・画像に対応。記法を覚える必要はありません
- **Excel風の表**：マウスでマス目をなぞって作成。Excelからの貼り付け・貼り戻しもできます
- **記事は入れ子にできる**：左のツリーで階層を作り、ドラッグで並べ替えられます
- **検索**：タイトルと本文（表の中身も含む）から探せます。全角・半角、カタカナ・ひらがなの違いは気にしなくて大丈夫です
- **完全オフライン**：外部への通信は一切ありません

## 使い方

### 1. 開く

`quine.html` をブラウザで開きます。Microsoft Edge を推奨します（Google Chrome でも動きます）。

### 2. 書く

1. 記事の右上にある **「編集」** を押します（画面上部がオレンジ色になります）
2. 初回だけ名前を聞かれます。記事の「最終更新者」として記録されます
3. 本文の上に出るツールバーで、文字の装飾や表・画像を入れられます
4. 記事の追加・削除は、左のツリーの「…」メニューから行えます

### 3. 保存する

1. 右上の **「保存」**（または Ctrl+S）を押します
2. 保存ダイアログが開いたら、**いま開いているファイルを選んで上書き** します

上書きしないと変更は残りません。画面上部に「未保存」と出ている間は、まだ保存されていません。

> ブラウザの設定で「ダウンロード時に保存場所を確認する」をオンにしておいてください。オフのままだと、ダウンロードフォルダに別のファイルとして保存されてしまいます。

### 新しいWikiを作る

右上のメニュー（≡）→ **「新規Wiki開設」** で、記事が空の新しいWikiファイルを作れます。

## 注意

- **同じファイルを2人が同時に編集すると、後から保存した方で上書きされます。** 編集は短い時間で区切り、こまめに保存してください
- 「編集」を押すと、ファイルの最新版を読み込み直してから編集が始まります（他の人の変更を消さないための仕組みです）
- 記事を書き込んだWikiファイルには、記事の中身がすべて入っています。公開の場所には置かないでください

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `quine.html` | 完成品。これ1つで動きます |
| `src/` | 元になるソースコード（見た目・動きを直すとき用） |

### src から作り直す方法

`src/` の中身を直したあとは、[Node.js](https://nodejs.org/) を入れた状態で、このフォルダで次を実行すると `quine.html` が作り直されます。

```
node src/build.js
```
