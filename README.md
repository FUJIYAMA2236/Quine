# QUINE

**HTMLファイル1枚で動く、社内向けのWiki（ドキュメント管理ツール）です。**

アプリと記事のデータが、すべて `quine.html` 1つのファイルに入っています。
サーバもインターネット接続も不要で、ファイルをブラウザで開くだけで使えます。

> [!IMPORTANT]
> **QUINE は「自分自身を書き換えて保存する」ファイルです。**
> 普通のアプリとは保存のしくみがまったく違います。ここを誤解したまま使うと、**書いた内容が消えたり、ほかの人の変更を上書きしてしまったりします。**
> 使う前に、すぐ下の「[最初に必ず読んでください](#最初に必ず読んでください自分自身を書き換えるファイルです)」を読んでください。

## 最初に必ず読んでください：自分自身を書き換えるファイルです

### しくみ

QUINE には、記事を保存しておくサーバやデータベースがありません。**記事のデータは `quine.html` というファイルそのものの中に入っています。**
そのため「保存」は、次のような流れになります。

1. `quine.html` をブラウザで開く
2. 記事を書く ― **この時点では、変更はブラウザの中にしかありません**
3. 「保存」を押す ― 最新の記事を詰め込んだ **新しい `quine.html` が、まるごと1つダウンロードされます**
4. 保存の画面で、**いま開いている元の `quine.html` を選んで上書きする**
5. ここで初めて、共有フォルダのファイルが新しくなります

つまり「保存」とは、**自分自身の新しい版を書き出して、元のファイルと差し替えること**です。
差し替え（上書き）まで終わらないと、保存したことになりません。

名前の由来である「クワイン」も、自分自身を書き出すプログラムのことです。

### よくある誤解と、そのとき起きること

| よくある誤解 | 実際は | 起きること |
| --- | --- | --- |
| 書いたら自動で保存される | 変更はブラウザの中にあるだけ | 保存せずに閉じると、**書いた内容は消えます**（閉じる前に確認は出ます） |
| 「保存」を押せば、共有フォルダのファイルが新しくなる | 「保存」は新しいファイルを**ダウンロードするだけ** | 保存の画面で元のファイルに上書きしないと、**共有フォルダのファイルは古いまま**です |
| ダウンロードフォルダにできたファイルでもよい | 別の場所・別の名前（例：`quine (1).html`）のファイルは、**まったく別のWiki**になる | ほかの人は古いファイルを見続け、**次に誰かが編集すると、あなたの変更は無かったことになります** |
| 保存の画面を「キャンセル」しても、「未保存」の表示が消えたから大丈夫 | ブラウザの中からは、ファイルが本当に保存されたか確かめられない。QUINE は**ダウンロードを始めた時点で「保存済み」と表示します** | 実際には何も保存されていません。もう一度「保存」を押してください |
| 2人で同時に編集しても、両方の変更がまとまる | 自動でまとめる機能はない | **後から上書きした人の内容だけが残り**、先に保存した人の変更は消えます |
| QUINE を新しい版にすれば、みんなのWikiも新しくなる | Wikiファイル1つ1つが、作ったときのアプリを**それぞれ中に持っている** | 古いWikiファイルは古い版のまま動きます。新しい機能を使うには記事を移し替えます（[後述](#quine-を新しい版にするとき)） |
| このファイルはアプリだけで、中身は別の場所にある | 記事も画像も**すべてこのファイルの中**にある | ファイルをメールで送ったり持ち出したりすると、**全部の記事を渡したこと**になります |

### 必要なブラウザの設定

保存の画面が出ないと、元のファイルに上書きできません。使う前に一度だけ、次の設定をしてください。

- **Microsoft Edge**：「設定」→「ダウンロード」を開き、**ダウンロードのたびに保存する場所をたずねる設定をオン**にする

この設定がオフのままだと、「保存」を押すたびに、ダウンロードフォルダに別のファイル（`quine (1).html` など）が増えていきます。

### 正しい保存の手順

1. 右上の **「保存」**（または Ctrl+S）を押す
2. 保存の画面で、**いま開いているファイルと同じ場所・同じ名前**になっていることを確かめる
   （共有フォルダの `quine.html` なら、共有フォルダを開いて `quine.html` を選ぶ）
3. 「置き換えますか？」と聞かれたら **「はい」**
4. 心配なときは、エクスプローラーでそのファイルの **更新日時** が今の時刻になっているかを見る

## 特徴

- **開くだけで使える**：インストール不要。共有フォルダに置いて、ダブルクリックで開きます
- **Word感覚で書ける**：見出し・太字・箇条書き・チェックリスト・リンク・画像に対応。記法を覚える必要はありません
- **Excel風の表**：マウスでマス目をなぞって作成。Excelからの貼り付け・貼り戻しもできます
- **記事は入れ子にできる**：左のツリーで階層を作り、ドラッグで並べ替えられます
- **検索**：タイトルと本文（表の中身も含む）から探せます。全角・半角、カタカナ・ひらがなの違いは気にしなくて大丈夫です
- **リンク候補の提案**：書いた記事の中に、ほかの記事のタイトルや見出しと同じ言葉があると、リンクの候補を出します。選んだものだけがリンクになります
- **完全オフライン**：外部への通信は一切ありません

## 使い方

### 開く

`quine.html` をブラウザで開きます。Microsoft Edge を推奨します（Google Chrome でも動きます）。

### 読む・探す

- 左側の「記事の一覧」から記事をクリックすると、右側に中身が出ます
- 上の帯の真ん中の「検索欄」に言葉を入れると、記事を探せます

### 書く

1. 記事の右上にある **「編集」** を押します
   - このとき、**ファイルの最新版を自動で読み込み直してから**編集が始まります（ほかの人が保存した内容を消さないためです）
   - 画面の上がオレンジ色になったら編集中です
2. 初回だけ名前を聞かれます。記事の「最終更新者」として記録されます
3. 本文のすぐ上に出るボタンで、文字の装飾や表・画像を入れられます
4. 記事の追加・削除・並べ替えは、左側の記事の一覧の「…」メニューやドラッグで行えます
5. 書き終わったら「編集を終える」を押します。ほかの記事とつながる言葉があれば、リンクの候補が出ます
6. **最後に必ず保存します**（[正しい保存の手順](#正しい保存の手順)）

### 新しいWikiを作る

右上のメニュー（≡）→ **「新規Wiki開設」** で、記事が空の新しいWikiファイルを作れます。
このとき作られるファイルにも、いま使っているアプリがそのまま入ります。

### 記事を持ち運ぶ（エクスポート・インポート）

- 記事の「…」メニューから、記事を JSON ファイルとして書き出せます（子記事・画像もいっしょに書き出せます）
- 書き出したファイルは、メニューの「インポート」か、画面へのドラッグで取り込めます
- 同じ記事がすでにある場合は、新旧を並べて見比べてから「置き換える／別記事として追加／やめる」を選べます

## 複数の人で使うとき

- **同じファイルを同時に編集しないでください。** QUINE には、ほかの人が編集中かどうかを知る手段がありません。後から上書きした人の内容だけが残ります
- 編集は短い時間で区切り、**書き終えたらすぐ保存**してください
- 「編集」を押すと最新版を読み込み直すので、**編集を始める直前に「編集」を押す**のが安全です。開きっぱなしの画面で長時間たってから書き始めないでください
- 誤って上書きしてしまったときは、相手に記事を「エクスポート」してもらい、自分が「インポート」すると、記事ごとに見比べて取り込めます

## バックアップ

Wiki は1つのファイルなので、**ファイルをコピーするだけでバックアップになります。**
大きな編集の前や、週に一度などの区切りで、日付を付けたコピー（例：`quine_2026-10-25.html`）を残しておくと安心です。

## QUINE を新しい版にするとき

Wikiファイルは、作ったときのアプリを中に持っています。**新しい版の `quine.html` を置いても、今あるWikiファイルは自動では新しくなりません。**
新しい版の機能を使いたいときは、次の手順で記事を移し替えてください。

1. 新しい版の `quine.html` を開き、メニューの「新規Wiki開設」で新しいWikiファイルを作る
2. 古いWikiファイルで、いちばん上の階層の記事ごとに「子記事も含めてエクスポート」する
3. 新しいWikiファイルで、書き出したファイルを順に「インポート」して保存する
4. 新しいファイルで問題がないことを確かめてから、古いファイルと入れ替える

## 動作環境

| 項目 | 内容 |
| --- | --- |
| ブラウザ | Microsoft Edge（推奨）。Google Chrome でも動きます |
| 置き場所 | 共有フォルダやパソコンの中。ファイルを開くだけで使えます（サーバは不要） |
| ファイルの大きさ | 画像を貼るほど大きくなります。右上のメニュー（≡）で今の大きさを確認できます |

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `quine.html` | 完成品。これ1つで動きます（記事は「はじめに」だけが入っています） |
| `src/` | 元になるソースコード（見た目・動きを直すとき用） |
| `LICENSE` | ライセンス（0BSD） |
| `THIRD_PARTY_NOTICES.md` | 参考にしたものの著作権表示・ライセンス文 |

> [!WARNING]
> 記事を書き込んだWikiファイルには、記事と画像がすべて入っています。**社内の資料が入ったファイルを、GitHub などの公開の場所に置かないでください。**

### src から作り直す方法

`src/` の中身を直したあとは、[Node.js](https://nodejs.org/) を入れた状態で、このフォルダで次を実行すると `quine.html` が作り直されます。

```
node src/build.js
```
